# Visualización del catálogo de Netflix

Análisis y visualización del catálogo de Netflix usando el dataset público con información de títulos, géneros, directores y países.

## Datasets incluidos

| Archivo | Descripción |
|---------|-------------|
| `netflix_titles.csv` | Catálogo completo de series y películas |
| `Cast.csv` | Actores por título |
| `Directors.csv` | Directores por título |
| `Countries.csv` | Países de producción |
| `Listed+In.csv` | Géneros y categorías |
| `Description.csv` | Sinopsis de cada título |
