# Análisis de ventas — Superstore

Análisis de ventas del dataset Superstore con tablas dinámicas en Excel y notebooks de Python.

## Stack técnico

- Excel — tablas dinámicas, análisis de KPIs por región, categoría y segmento
- Python — exploración y visualización con pandas y plotly

## Estructura

```
superstore-analysis/
├── DinamicTables_Nivel2.xlsx   ← análisis en Excel con tablas dinámicas
├── datos/                      ← dataset de ventas
└── notebooks/                  ← análisis exploratorio en Python
```
