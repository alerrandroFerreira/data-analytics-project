# Análisis de ventas — Classic Models

Análisis de la base de datos Classic Models (distribuidora de coches en miniatura) usando SQL y Power BI.

## Stack técnico

- SQL — consultas de análisis sobre la base de datos relacional
- Power BI — dashboard de KPIs de ventas

## Estructura

```
sales-analysis-classicmodels/
├── classicmodelsscript.sql   ← script principal de consultas
├── sql-practice/             ← consultas de práctica y exploración
└── powe-bi-classicmodels/    ← archivo .pbix con el dashboard
```
